# 数学哈哈漫画编辑部

面向小学一至二年级的数学喜剧漫画智能体提示词与协作流程。每篇默认六格、一个数学思想、两个主要角色。用角色的愿望、误会和行动推动数学理解，再用反转收尾。

这是可在聊天窗口或多智能体平台使用的文本创作套件，不是自动运行的应用。不需要安装依赖，也不需要 API 密钥。

## 开始使用

1. 从 [创作任务模板](templates/brief.md) 填写一篇漫画的目标。
2. 给每个智能体粘贴 [公共提示词](prompts/common.md)，接着粘贴其角色提示词。聊天窗口可以每阶段开一个新对话；无需先部署平台。
3. 按 [协作流程](WORKFLOW.md) 传递完整任务书与上一阶段产物。两位审校分别看同一份稿件，不先阅读对方结论。
4. 根据问题清单修改，再将审校后的分镜交给视觉设计师。
5. 生成图像后，重新检查数量、遮挡、文字和连续性。未检查的成图不能标为完成。

## 智能体

| 角色 | 提示词 | 输出 |
|---|---|---|
| 总编 | [总编](prompts/editor.md) | 任务书、阶段安排、最终交付 |
| 数学策划 | [数学策划](prompts/math-planner.md) | 单一目标、误解、直观验证、关键条件 |
| 喜剧编剧 | [喜剧编剧](prompts/comedy-writer.md) | 两个提案、选定故事、对白 |
| 分镜导演 | [分镜导演](prompts/storyboard-director.md) | 逐格动作、对白、物品数量 |
| 视觉设计师 | [视觉设计师](prompts/visual-designer.md) | 角色设定、逐格绘图提示词、检查清单 |
| 数学审校 | [数学审校](prompts/math-reviewer.md) | 数学问题及修改建议 |
| 儿童阅读编辑 | [儿童阅读编辑](prompts/reading-editor.md) | 阅读障碍、笑点预判及修改建议 |

角色是逻辑上的分工；在普通聊天窗口中可以逐个使用，无需同时运行七个模型。

## 三篇示例

| 示例 | 数学思想 | 笑点来源 |
|---|---|---|
| [谁的鱼饼干多？](examples/01-fish-crackers.md) | 排列改变，数量不变 | 为了把饼干摆远，吃饭变成远足 |
| [袜子坐错车](examples/02-sock-bus.md) | 按同一标准分类 | 袜子被当成乘客，想抢靠窗座位 |
| [尾巴也要坐？](examples/03-tail-chair.md) | 一一对应比较，找出多余的物品 | 小猫替尾巴预订椅子 |

示例包含任务书、分镜、绘图提示词及文本审阅记录。《谁的鱼饼干多？》已有 [六格成品](outputs/fish-crackers/comic-v1.png) 和 [成图检查记录](outputs/fish-crackers/README.md)，另外两篇尚未绘图。三篇均没有经过真实儿童试读；检查记录不能证明孩子觉得好笑。

第一轮可先只做脚本，用示例对照检查产物。需要绘图时再选择图像工具；本套件不绑定服务商。
