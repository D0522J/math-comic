# 第4页局部修正指令

初稿交付中漏画已放入蓝顶亭的一篮，人物反应格只显示三处补给，末格背包重复出现。以下记录实际局部编辑指令；正确性以修正版目视核对为准，不能用本指令代替检查。

```text
对所附《四篮果子的雨林快递》第4页做局部修正，保留五格结构、全部中文对白、标题页码、人物造型、明快雨林画风。数学任务是四个亭子、四只藤篮、每篮恰好三个红果，总十二果。不要重绘第1和第3和第5格现有正确的四篮水果，不多加水果，不让人吃水果。
修正1：右上第2格，交付途中应该已送到两个亭各一篮、阿冲手中一篮、提架上还一篮，总四篮。现在黄顶亭已经一篮、阿冲手中一篮、提架上有一篮，但右上方蓝顶亭的平台空着。请在右上第2格画面上方蓝顶休息亭的空平台中央增加恰好一只与其他篮子一致的浅藤篮，篮内恰好三枚红果，三角形摆放、不重叠。保留现有黄顶亭的一篮、阿冲手中的一篮、提架上的一篮完全不变。修正后2亭内2篮+手里1篮+提架1篮，总4篮12果。其他两个亭仍空。蓝亭新增篮要清楚可数三果，不可增加第五篮。
修正2：右中第4格（小满展示路线板、阿冲摆英雄姿势），背景只清楚看见三个放果篮的平台，请调整这一格的背景空间、在合适空档补足缺失的第四个黄色屋顶低亭平台与一只三果藤篮。保留原有三个亭中的三果篮，不改变人物对白、记录板、动作与大笑表情。可以略调整背景透视让四处补给都可辨认，人物不缩成小点。修正后是黄色、红色、蓝色、绿色四个亭子，每亭恰好一篮、每篮三果，共十二果；不能在地上另外加第五个篮来替代缺的亭子。背景要自然、避免被大气泡挡住全部新篮子。
造型连续性小修正：
- 左中第3格有两个黄色屋顶，请把左下那个黄色亭子的屋顶改为红色，其他三个仍黄色、蓝色、绿色，四个亭子用四种颜色区分，其篮内水果都不变。
- 底部第5格阿冲肚子咕噜叫时背包已卸下。保留他左边地上那一个绿色大背包与绑在旁边的折叠叶伞，删除他背上多余的第二个绿色背包与背包肩带，恢复白色短袖和红披肩；腰带裤子不变。全格仅一个绿色背包放地上，不能多包。四亭各一三果篮仍全部保留。
所有中文原样保持：“每个亭子送一篮。”“快递！快递！”“四篮都送齐啦！”“队长，路其实很短呀！”“队长也要补给！”以及肚子拟声“咕噜”。只一只绿鹦鹉、两个人类孩子，不能加新角色。最终保持漂亮、高可读、明确完成四篮任务的喜剧收尾。
```

## 第二次：反应格完整四亭视角

第一次编辑修好了交付漏篮和重复背包，但反应格仍只显示三处补给。第二次只重画反应格为更宽视角，修正版已目视确认四亭各一篮、每篮三个。

```text
只重画所附五格漫画中的右中第4格（画面右半边中间，小满拿路线板、阿冲得意叉腰的那格）。其他四格、标题、页码、分格、全部文字、全部水果数量保持原样，包括右上格已修好的2篮在亭子+1篮手中+1篮提架，绝对不能改坏其他格。
第4格改为稍微更宽的视角，人物阿冲、小满、嘎嘎仍在前景，造型和夸张表情原样，阿冲叉腰笑，小满展示短路线，嘎嘎在地面。绿色背包在地面。对白原样“队长，路其实很短呀！”气泡尾巴指小满。
关键必须完成：这一格的背景必须清晰露出四个小休息亭的平台，每个平台恰好一只浅藤篮、每篮恰好三枚红果，总共四篮十二果。现图只看得到三篮，需要完整四篮。可将背景四个亭子按较宽弧线排在人物身后，依次黄顶、红顶、蓝顶、绿顶，给每个平台留空间，必要时把两个人物略缩小一点但表情仍清晰。让气泡放在上方留白，不盖住四个篮口。不在地上凭空添加一个散篮；必须四个亭各一篮。三枚果以不重叠三角形可见，不能每篮2或4。
这不是在同一个亭子加第二篮，也不是新增第五个亭子。只把第4格取景画宽，使原有四个亭子和四篮都完整可见。保留雨林、树根、木平台、节庆旗和温暖饱满画风。只改这一格，其他格完全保持。
```
