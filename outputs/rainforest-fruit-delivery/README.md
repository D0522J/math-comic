## 场景、动作和数学任务

人物为阿冲、小满、嘎嘎；咚咚本篇未出场。四个空篮从营地经树根路带到果园，补给台实际装篮后进入栈道运输，最终到树屋广场逐篮交付。人物造型和夸张表情沿用概念图。

营地的背包卡门、果园的装篮发现错误、栈道的叶伞挡脸、树屋的英雄肚子叫形成喜剧推进。只在果园页显示算式，不在每个地点重复讲课。

## 修正与技术核对

- 第2页删除装篮时手中多画的果子，并补回补取格遗漏的原有单果，修正版数量已重新核对。
- 第4页补回交付中蓝顶亭的果篮；将人物反应格改为更宽视角，明确显示四个收货处；删除结尾重复背包，服装保持一致。
- 四页中文对白与脚本含义一致，气泡归属正确；第2页两条算式清楚正确。
- 四页原图和PDF页数、顺序、图像尺寸与链接均已检查。PDF不修改原图像素。
- 实际使用图像工具直接生成对白与算式，未单独进行后续排字；成图后已逐句核对。

数学核对依据具体物品状态和实际图像，不以提示词中的数量要求作为通过证据。真实儿童试读未进行，不能据此保证孩子觉得好笑或已学会乘法。
