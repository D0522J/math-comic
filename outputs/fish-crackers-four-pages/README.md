## 人物搞笑与故事时间线

团团把吃点心当远征，背大包、带睡袋；点点把勺子当话筒，隆重播报小事。四页依次展开准备、误会与发现、远征意外、合作解决和喜剧回扣。

第2页明确纠正“摆开就是更多”；之后团团改玩排列游戏，而不是重新相信错误结论。第3页画出短包带勾住椅背的原因，第4页解除连接、收回饼干，最后肚子先叫起来。
