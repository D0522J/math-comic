# 雨林哈哈探险队：角色与场景概念图 v1

[查看概念图](concept-v1.png)

图像为1024×1536像素 PNG，展示原创角色阿冲、小满、咚咚、嘎嘎，常态造型与夸张表情小样，以及营地、树根果园、蕨叶栈道、树屋广场四处场景。

此图是人物与场景设计参考，不是《四篮果子的雨林快递》的20格成品，也不呈现该篇的教学数量。多处出现同一人物和鹦鹉是设计小样，不代表故事中新增角色。果园场景可包含全队成员，正式第一篇按脚本只使用阿冲、小满和嘎嘎。

## 目视检查

- 阿冲黄帽红披肩、大背包；小满青绿发带黄雨衣、记录板；咚咚橙帽蓝背带裤、工具；嘎嘎叶帽，轮廓和道具不同。
- 主造型与小头像展示大笑、瞪眼张嘴、憋笑等表情，避免所有角色只微笑。
- 场景地标可区分：帐篷与树根、果园补给台、蕨叶与栈道、树屋与平台。
- 动作笑点可见：包卡帐篷、鸟探记录板、叶伞盖脸、英雄肚子先叫。
- 没有把概念图中的道具数量当成数学审校结果；正式20格须按脚本逐格检查。

检查为本助手目视自审，非独立智能体调用或真实儿童反馈。
