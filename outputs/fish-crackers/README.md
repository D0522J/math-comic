# 《谁的鱼饼干多？》成品 v1

[查看六格漫画](comic-v1.png) · [原始脚本](../../examples/01-fish-crackers.md)

原创中文儿童漫画，面向小学一至二年级。成品为1024×1536像素 PNG，标题加两列三行的六格故事。

角色：橙猫团团穿绿色背带裤；灰猫点点穿蓝色上衣。数学目标：拉大物品间距不会增加数量。

## 成图目视检查

检查由本助手对生成图像直接目视完成，不是独立模型审校，也不是真实儿童试读。

| 格 | 点点的饼干 | 团团的饼干 | 对白与画面 |
|---|---|---|---|
| 1 | 3 | 3 | “每人三块！”；两组均清楚可见。 |
| 2 | 3 | 3 | “我的多！”；团团拉开间距，故意作出错误判断。 |
| 3 | 3 | 3 | “一、二、三。”；点点指向团团的饼干，进行点数。 |
| 4 | 3 | 3 | “还是一样多呀！”；点点指向自己的三个，纠正误解。 |
| 5 | 3 | 3 | “那我再摆远点！”；只变化间距，没有新增饼干。 |
| 6 | 3 | 3 | “吃饭还要去旅行？”；团团背包举餐叉走向远端饼干。 |

六格均共6块饼干，没有吃掉、遮住或重复画出的额外饼干。标题两侧的鱼饼干是标题装饰，不属于任何一格的桌面计数对象。透视使近处饼干看起来略大，教学仅比较数量，不推断食物大小或份量相等。

六句对白清晰，气泡归属与角色行为相符；第3、4格纠正第2格错误。角色服装保持一致，结尾的背包和餐叉支持旅行笑点。

## 与文本脚本的调整

- 最后一格将“吃饭还要远足呀？”改为“吃饭还要去旅行？”，便于低年级理解。
- 成品直接生成中文对白，没有采用文本方案中默认的后续独立排字流程；生成后已逐句目视核对。
