# 团团与点点：搞笑角色卡

适用读者：小学一至二年级。人物的搞笑元素必须在动作、造型和重复行为中出现，不能只写在简介里。

## 团团：把小事当大冒险

- **固定外观：**橙色小猫、绿色背带裤。表情变化大，但不靠身体缺陷制造笑话。
- **搞笑道具：**一个明显超出日常需要的绿色旅行背包，外侧绑着小睡袋。道具颜色和结构跨页一致。
- **行为习惯：**吃点心也认真准备旅行装备，摆桌子也像安排远征；做一件小事，却带一堆用不上的东西。
- **核心愿望：**点心更多、事情更有趣，喜欢尝试自己的小聪明。
- **表情动作：**想到办法时得意叉腰；被事实提醒时挠头；准备行动时夸张地高抬腿。
- **喜剧铺垫：**开饭前背着大包，点点发现里面竟有睡袋。
- **升级：**为了走到摆远的饼干旁边，真的背包出发。
- **回扣：**背包带子勾住自己的椅背，连椅子也被“带去旅行”；最后放下装备，回到桌边。
- **不变条件：**他愿意改错，明白数量没变后，不无故重新声称变多；可以继续玩排列游戏。

## 点点：一本正经的现场播报员

- **固定外观：**灰色小猫、蓝色上衣，体型与团团接近。
- **搞笑道具：**一把普通勺子，常举到嘴边当“话筒”。不把勺子画成食物或额外饼干。
- **行为习惯：**认真宣布极小的事情，像正在直播重大事件；越小的事，宣布得越隆重。
- **核心愿望：**顺利吃到点心，也愿意参与团团的游戏。
- **表情动作：**端正坐好举勺播报；遇到团团的过度准备时歪头；结尾忍笑举勺宣布开饭。
- **喜剧铺垫：**用勺子郑重宣布“点心时间到”。
- **升级：**给三块饼干认真“报数”，又发现团团把椅子也带走。
- **回扣：**郑重宣布“旅行结束”，两只猫其实还没离开点心桌。
- **不变条件：**不是持续讲课的老师；通过指、数、帮忙和短句参与故事。

## 两人的互动与绘图约束

团团把小事放大，点点把大阵仗拉回眼前，两人一起把问题变成游戏。点点可以吐槽行为，但不侮辱团团。

背包、睡袋、勺子都必须在指定页格出现并保持一致。道具不能遮住关键数学对象。餐叉在需要时从背包取出，避免在每一格无故消失或变形。

允许夸张的衣服、道具、姿势和表情；不要靠外貌羞辱、危险模仿或“这个角色笨”制造笑点。
